## Oryginalne archiwum ZIP

Oryginalny plik `archiwum_krosno_laznia_Grobla64.zip` jest dostępny publicznie jako asset wydania GitHub:

- [Pobierz oryginalne archiwum ZIP](https://github.com/Dobrychlopak87/IZA/releases/download/archiwum-oryginalne/archiwum_krosno_laznia_Grobla64.zip)

GitHub nie pozwala przechowywać pojedynczych plików większych niż 100 MB w zwykłym repozytorium, a limit Git LFS tego konta został wyczerpany. Dlatego ZIP jest opublikowany w wydaniu repozytorium, natomiast wszystkie jego pliki są dostępne poniżej w postaci rozpakowanej.
